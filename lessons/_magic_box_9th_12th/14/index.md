### Project Overview

Complete the automatic Magic Box by adding an ultrasonic distance sensor. You’ll learn how the sensor measures distance, work through the math behind it, and program the box to open and close when someone approaches.

### Key Topics

- How an ultrasonic distance sensor works
- Calculating distance from echo timing
- Opening and closing the Magic Box based on distance

Congratulations—you've completed the Magic Box tutorial series! Now that your box can sense when someone approaches and open automatically, experiment with your own ideas.
