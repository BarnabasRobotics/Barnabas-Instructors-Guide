### Wiring and Coding The Servo Motor

In this lesson, you will add the servo motor—the part that creates the movement needed to open your Magic Box.

### What You'll Learn

- Connect the servo motor as demonstrated
- Use block-based code to control servo position
- Test the servo before attaching it to the box

### Follow Along

1. Wire the servo by following the connections shown in the video.
2. Create the servo code and test its movement.
3. Pay attention to the servo's starting and ending positions; these will matter when you assemble the box.

### Check Your Work

Before moving on, make sure your project behaves like the example shown in the video. If something isn't working, compare your wiring and code carefully with the video before changing multiple things at once.

### What's Next?

Next, you'll assemble the box and use the servo to make it open.
