It's time to combine mechanical design with electronics. You'll assemble the box and connect the servo's movement to the lid.

### What You'll Learn

- Assemble the physical Magic Box
- Connect servo movement to the opening mechanism
- Adjust the code so the box opens correctly

### Follow Along

1. Assemble the box along with the video.
2. Install the servo and opening mechanism in the demonstrated position.
3. Run your servo code and watch the lid movement.
4. Make small adjustments if the lid does not open or close as expected.

### Check Your Work

Before moving on, make sure your project behaves like the example shown in the video. If something isn't working, compare your wiring and code carefully with the video before changing multiple things at once.

### What's Next?
