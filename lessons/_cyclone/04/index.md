### Creating the Cyclone Light Sequence

One blinking LED is just the beginning. Now you'll program all of the LEDs to light in sequence around the game board, creating the moving-light effect at the heart of the classic Cyclone arcade game.

### What You'll Learn

- Control several LEDs in a programmed sequence
- Use repeated patterns to organize code
- Create the moving-light effect used by the Cyclone game

### Follow Along

1. Build the light sequence by following the coding steps in the video.
2. Run the program and confirm that the LEDs move around the circle in the correct order.
3. If the sequence skips a light or runs out of order, compare the code and wiring for that LED.

### Check Your Work

Before moving on, make sure your project behaves like the example shown in the video. If something isn't working, compare your wiring and code carefully with the video before changing multiple things at once.
