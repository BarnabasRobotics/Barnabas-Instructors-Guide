### Adding the Player Button

Your Cyclone game has lights, but a game also needs a way for the player to interact with it. In this lesson, you'll wire the pushbutton that players will press to try to stop the moving light at just the right moment.

### What You'll Learn

- Wire a pushbutton into the Cyclone circuit
- Understand the button as an input device
- Trace how a physical button connects to the Uno board

### Follow Along

1. Position the button as shown in the video.
2. Connect the button wiring carefully to the correct locations.
3. Trace each connection before moving on to programming the button.

### Check Your Work

Before moving on, make sure your project behaves like the example shown in the video. If something isn't working, compare your wiring and code carefully with the video before changing multiple things at once.

### What's Next?

Next, you'll program the Uno to detect when the player presses the button.
