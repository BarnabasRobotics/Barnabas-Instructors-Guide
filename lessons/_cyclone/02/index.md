### Wiring the Cyclone Lights

Now it's time to connect all of the lights that make the Cyclone game come alive. You'll build the LED circuit one connection at a time and see how the Uno board, breadboard, jumper wires, and LEDs work together.

### What You'll Learn

- Wire multiple LEDs to the Arduino-compatible Uno board
- Use a breadboard to organize electrical connections
- Practice tracing and checking a circuit before adding code

### Follow Along

1. Follow the wiring diagram and video carefully as you connect each LED.
2. Keep your jumper wires organized so you can trace each connection.
3. Before coding, compare every LED connection with the example in the video.

### Check Your Work

Before moving on, make sure your project behaves like the example shown in the video. If something isn't working, compare your wiring and code carefully with the video before changing multiple things at once.
