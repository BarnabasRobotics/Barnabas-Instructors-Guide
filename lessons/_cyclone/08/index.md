### Adding the Servo Motor

Your game can now recognize a winner. In this lesson, you'll add a servo motor so the Cyclone can do more than flash lights—it can create physical movement as part of the winning experience.

### What You'll Learn

- Identify the servo motor connections
- Attach and wire a servo motor to the game
- Understand how a servo adds controlled movement to a project

### Follow Along

1. Attach the servo motor in the location demonstrated in the video.
2. Connect the servo wires to the correct power, ground, and control connections.
3. Double-check the servo wiring before powering or programming the motor.

### Check Your Work

Before moving on, make sure your project behaves like the example shown in the video. If something isn't working, compare your wiring and code carefully with the video before changing multiple things at once.
